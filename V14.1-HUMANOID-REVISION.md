# TemmuzOnline Jarvis v14.1 — Humanoid / Voice Revision

Bu paket, kullanıcının gönderdiği son v14 release-gate-real ZIP'i temel alınarak yerinde güncellenmiştir. Proje sıfırdan kurulmamıştır.

## Değiştirilen ana parçalar
- `outputs/orb-engine.js`: ana dashboard için özgün WebGL2 particle humanoid, assembly/state/audio reactivity; kompakt orb korunur; WebGL2 yoksa 2D fallback.
- `outputs/voice-client.js`: microphone/TTS analyser smoothing, wake-word akışı, state FX, AI TTS ve browser TTS fallback davranışı.
- `outputs/tts-service.cjs`: instruction-capable OpenAI TTS modelleri için opsiyonel Türkçe konuşma stili.
- `outputs/operations-v12.js`: voice state HUD senkronu ve wake-word yeniden dinleme.
- `outputs/temmuz_jarvis_v12_operations.html`: humanoid HUD ve AI voice disclosure.
- `outputs/operations-v12.css`: yeni merkez sahne, enerji alanı ve humanoid HUD katmanları.
- `.env.example`: `TTS_INSTRUCTIONS`, örnek `cedar` voice.
- `tests/business.cjs`: TTS instruction davranışı için test.
- `package.json`: sürüm `14.1.0`.

## Görsel durumlar
`ASSEMBLING → IDLE / WAITING_WAKE_WORD / LISTENING / THINKING / SPEAKING / ERROR`

Humanoid APEX'in ücretli humanoid kaynak kodunu içermez. Referansın fonksiyonel prensiplerinden ilham alınarak TemmuzOnline için sıfırdan yazılmış özgün WebGL2/Canvas uygulamasıdır.

## Testler
Bu ortamda başarıyla çalıştırıldı:
- `node --check outputs/orb-engine.js`
- `node --check outputs/voice-client.js`
- `node --check outputs/tts-service.cjs`
- `node --check outputs/operations-v12.js`
- `node tests/v14.cjs`
- `node tests/council.cjs`
- `node tests/business.cjs`

Tam `npm test` çalıştırılmadı; çalışma ortamı npm registry erişiminde `EAI_AGAIN` verdi ve ZIP içinde production `package-lock.json` bulunmuyor. Production repo'daki mevcut lock dosyası korunmalı, gerçek repo üzerinde `npm ci && npm test` çalıştırılmadan Render deploy yapılmamalıdır.

## Render için ek opsiyonel değişken
`TTS_INSTRUCTIONS` yalnızca TTS modelinin instruction desteklediği durumda gönderilir. Secret değildir; gerçek API key hâlâ sadece Render Environment Variables içinde tutulmalıdır.
